fix(settings): סעיף 33 - סינון גלובלי שנוקה חזר אחרי מיון ("20 מתוך 20")

user.settings הוא עמודת JSON אחת שמשותפת לכל המסכים. כל מסך טען את
המשתמש, שינה מפתח משלו ושמר את כל האובייקט - האחרון ששמר ניצח. TableState
החזיק את העותק שטען בפתיחת הרשימה, ובכל מיון כתב אותו חזרה - כולל סינון
גלובלי שהמשתמש כבר ניקה. הבר הראה ריק, השרת סינן.

- UserSettingsController (חדש): הכותב היחיד. קורא את השורה טרייה בשרת
  ומשנה מפתח אחד בלבד - set (החלפה) / merge (מיזוג רדוד, null מוחק שדה).
  רשום ב-api.ts; גם ה-beacon של סגירת לשונית עובר דרכו.
- UserSettingsService (חדש): נקודת הכניסה בקליינט, ושומר את התוצאה על
  remult.user.settings.
- הועברו אליו: TableState (כל הרשימות), סרגל צד, חיפוש גלובלי, מתכנן מסלול,
  מפה, דוחות, ניקוי מילת חיפוש שמורה (תורמים, תזכורות).
- GlobalFilterService: שמירה אחת בכל פעם (תור); הבר מתעדכן רק אחרי שמירה
  מוצלחת; בכישלון - נטען מחדש מהשרת. קריאה עם useCache:false.

לא נמחק: saveSortSettings בתעודות ובתזכורות (לא נקרא מאף מקום).

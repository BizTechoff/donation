fix(donor-gift): החיפוש מצמצם את הסינון במקום לדרוס אותו

בחירת תורם ספציפי ב"בחר תורם" יחד עם הקלדה בתיבת החיפוש - הבחירה נעלמה
בשקט, והתוצאות חזרו לכל מי שתואם את הטקסט:

    if (localFilters.selectedDonorId) whereClause.donorId = ...selectedDonorId
    ...
    whereClause.donorId = { $in: searchDonorIds }   // דורס

החיפוש קיבל את הסינון הגלובלי כפרמטר אך לא את התורם הנבחר, ואז השים על אותו
שדה. אותה משפחה כמו הבאג בתזכורות: לא נופל, מחזיר תוצאה סבירה למראה, רחבה
מדי.

בניית ה-where רוכזה ל-buildWhereClause פרטית אחת - הבלוק היה משוכפל שלוש
פעמים (עמוד, ספירה, סטטיסטיקה) ושלושת העותקים נשאו את אותו פגם. המבנה זהה
ל-certificate.controller, שכבר עושה זאת נכון. הפונקציה מחזירה null כשהסינון
אינו יכול לתאום דבר, וכל קורא מחזיר את הריק שלו (רשימה / 0 / זוג אפסים).
טעינת הפילטרים הגלובליים של המשתמש רוכזה גם היא, ל-loadGlobalFilters.

שינויי התנהגות:
- החיפוש מוגבל כעת לתורם הנבחר אם נבחר, ואחרת לסט הגלובלי.
- בקשת תורם שהסינון הגלובלי מוציא מחזירה ריק במקום לעקוף את הסינון.

בחירת שנה עדיין דורסת בכוונה את סינון התאריכים הגלובלי - זה היה מתועד ונשמר.
